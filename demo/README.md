# 人体新视角教学原型

双击 `index.html`，使用 Edge 或 Chrome 即可离线运行。无需安装任何依赖，无需联网。

## 已实现

- 程序生成的三维人体表面点元，以及简化圆形渐变 splat 绘制。
- 相机旋转、俯仰、缩放；真实三维坐标投影，而非二维图片拉伸。
- 手臂、腿部的分段刚性旋转与预设步态。
- 服装区域改色，预设语义标签筛选。
- 可选正面照片固定投影贴色；PNG、点云 PLY 与实际绘制时间 JSON 导出。

## 必须如实介绍

这是算法思想教学原型，不是训练过的 AI 模型，不是三篇论文复现，也没有完成课程的真实照片人体重建 Baseline。人体来自人工参数化椭球组合，标签由程序指定。没有 SMPL/SMPL-X、可微渲染训练、骨骼权重学习、扩散服装生成、SAM 或语言模型。

照片输入只给固定模板正面取色，需白底、居中、全身、正面，不能恢复真实体型、遮挡或背面。PLY 是普通带颜色的三维点云，不是论文高斯模型权重，不能当作 3DGS checkpoint。

绘制时间是浏览器端投影、排序和 Canvas2D 绘制调用耗时，不是神经网络推理速度；未等待 GPU 完成。不能用它与论文 FPS 直接比较，也没有 PSNR/SSIM 真值指标。

## 三分钟演示

1. 指出顶部实验边界，解释这是第七周的交互原型。
2. 切换正面、侧面、背面，说明同一个三维模板从不同视角投影。
3. 调节手臂、播放步态，说明人体先验和关节变换的思想（参考 GauHuman）。
4. 修改上衣颜色，选择上衣并只显示该区域，说明区域隔离思想（参考 T3HG-Editor），不是生成新衣服。
5. 选择语义区域，说明给三维元素附加语义信息的思想（参考 Feature4X），标签来自人工定义。
6. 导出一张 PNG 和一次测量 JSON；解释后续要接入真实重建模型。
