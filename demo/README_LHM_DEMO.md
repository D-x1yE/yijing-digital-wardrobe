# LHM++ 数字人及动作演示

双击本目录的 `start_lhm_demo.cmd`，自动启动/复用本地服务并打开 http://127.0.0.1:8770/lhm.html 。

## 操作与答辩流程

1. 上传 1–4 张同一人物、同一套衣服的照片；也可以点击“选择双视角样例”。
2. 选择舞蹈、太极或跳跃，点击“生成数字人与动画”。“仅生成静态三维”保留原有功能。
3. 等待照片预处理、模型加载、三维重建、骨骼驱动和逐帧渲染。首次演示建议留出约 1–3 分钟，实际取决于照片和机器负载。
4. 完成后在“动作视频”点击播放，可循环观看并下载 MP4；下方可旋转查看静态三维人物，下载 Gaussian PLY 或截图。
5. 现场可直接选择历史中带“舞蹈 / 太极 / 跳跃”的已完成任务展示，不需要每次重新生成。

## 已接入范围

- 官方 `LHMPP-700M-SMPLX-FREE` 权重；严格加载 checkpoint，采用 BF16 神经网络 / FP32 几何及稀疏卷积以适配 RTX 4060 Laptop 8GB。
- 重建一次后复用该人物的高斯属性和预测体型，以官方 `animate_gs_model` 和 SMPL-X 蒙皮驱动每一帧。
- 使用 gsplat 渲染真实姿态化三维高斯，编码为 H.264 / yuv420p MP4；不是对一张图片做平移或变形特效。
- 舞蹈取源 60fps 的每 4 帧，太极取源 30fps 的每 2 帧，两者输出 72 帧 / 15fps（4.8 秒）。跳跃输出 76 帧 / 30fps（约 2.53 秒）。
- 输出最长边 512 像素并对齐到 16；当前是纯高斯 RGB 渲染，不含官方神经渲染增强。
- 网页三维查看器仍显示静态规范姿态；动作在视频中播放。尚未提供网页动态三维自由视角、上传动作视频、语言编辑或换装。

## 文件及复现

- `serve_studio.py`：任务 API、预处理、串行启动 GPU 任务。
- `run_lhm_verify.py`：模型加载、重建与静态导出；第三个参数可附加 `Dance_I`、`TaiChi` 或 `Jump` 调用动作渲染。
- `lhm_animation.py`：官方骨骼驱动、逐帧高斯渲染与 MP4 编码。
- `download_lhm_motions.py`：下载官方 LHMPP-Assets 动作素材并检查 SHA-256；当前已下载，无需重复。
- `studio_results/<任务ID>/`：静态 PLY、输入、动画 MP4、首中尾帧、`animation.json` 验收参数及日志。

WSL Python 环境为 `/opt/lhm-venv`，模型在 `vendor/LHM-plusplus-main/pretrained_models/`；Windows 预处理与服务使用 `E:\555\envs\sd_torch\python.exe`。

不要同时在 DiGS 网站运行 GPU 生成，两套服务的任务锁相互独立。照片遮挡、服装变化及未观测区域可能造成纹理、形状或运动失真。模型、人体先验和官方动作素材遵循各自许可证。原 DiGS 及第七周旧演示入口保留。

## 2026-11-26 实机验收

三个预设都完成真实生成，MP4 帧数和帧率与元数据匹配，所有动画高斯属性及渲染输出有效。舞蹈通过网页按钮以双图生成，网页实际播放成功，下载文件与原 MP4 的 SHA-256 一致；太极、跳跃通过同一 API 以单图生成。无效动作及超过 4 图的输入会被拒绝并释放任务锁。
